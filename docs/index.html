核心功能

按角色划分的模块化单体实现，权限与业务规则层层校验。

🔐认证授权

JWT 双令牌 + RBAC 三角色 + 登录限流与刷新轮换，密码 BCrypt 加密。

📣活动与报名

活动状态机（草稿→招募→进行→结束→归档），报名审核流，名额原子扣减防超卖。

✅签到与工时

签到时间窗校验 + 重复签到拦截，RULE_V1 规则核算工时，支持手动 / 扫码签到。

📜档案与证明

周期证明按学年签发，自动汇总工时，实时生成 A4 中文 PDF 并支持下载。

📊统计可视化

ECharts 看板：总览指标、月度趋势、类型分布、热门活动与志愿者排行。

🛠️系统管理

用户管理、角色分配、公告发布、活动类型维护、全量操作审计日志。

🖼️活动封面上传

图片类型/大小白名单校验，UUID 命名，静态资源 CDN 式访问，卡片封面展示。

🔳扫码签到

组织者一键生成签到二维码，志愿者扫码进入签到页确认后完成签到（method=QR）。

📄证明 PDF

OpenPDF 嵌入系统中文字体，签发即生成电子版，编号防伪、可在平台核验。

快速开始

克隆后按 README 启动；演示数据脚本一键灌入。

# 1. 后端（需 JDK17 / Maven / MySQL8 / Redis）
cd backend && mvn spring-boot:run

# 2. 前端
cd frontend && npm install && npm run dev

# 3. 灌入演示数据
mysql -uroot -p volunteer -e "source sql/demo_data.sql"

# 4. 访问
http://localhost:5173   # 开发调试
http://localhost        # Nginx 生产入口
